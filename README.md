Шапка залишається на місці, а завантаження та помилки показуються на сторінці.
Текст пошуку зберігається в URL, а replace не додає кожну зміну тексту в історію браузера.
AbortController скасовує попередні запити, щоб не заважати новим.
Перевірки допомагають уникнути помилок, якщо API не повертає потрібні дані.
