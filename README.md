Шапка залишається на місці, а завантаження та помилки показуються на сторінці.
Текст пошуку зберігається в URL, а replace не додає кожну зміну тексту в історію браузера.
AbortController скасовує попередні запити, щоб не заважати новим.
Перевірки допомагають уникнути помилок, якщо API не повертає потрібні дані.

Обране зберігається в Context, оскільки список серіалів використовується в різних частинах застосунку:
у картках,
на сторінці серіалу,
у лічильнику в шапці,
на сторінці обраного,
тому передавати його через props було б незручно.
Форма «Мій відгук» є controlled, оскільки всі її значення зберігаються в state React, що дозволяє керувати полями, перевіряти введені дані та відновлювати збережений відгук.
Сторінку обраного розміщено в DetailLayout: так зберігається звичайна шапка в якій можна повернутись до каталогу, а якщо список обраного порожній то з'являється пропозиція повернутись на головну сторінку і зайнятись пошуком.
